# SmartContest

## Description

SmartContest est une solution SaaS permettant d'organiser et de gérer des compétitions sportives de manière simple et efficace.

## Documentation

La documentation utilisateur est disponible dans le dossier `docs/` et utilise Sphinx pour la génération.

### Structure de la documentation

- `index.rst` : Page d'accueil et table des matières principale
- `create-competition.rst` : Guide pour créer une nouvelle compétition
- `design-competition.rst` : Guide pour concevoir et configurer une compétition

### Génération de la documentation

Pour générer la documentation HTML :

```bash
cd docs
make html
```

La documentation générée sera disponible dans le dossier `docs/_build/html/`.
