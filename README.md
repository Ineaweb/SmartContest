# SmartContest - Documentation

📚 **Documentation complète de SmartContest** - Plateforme de gestion de concours moderne avec interface utilisateur intuitive.

## 🎯 Aperçu

SmartContest est une plateforme complète pour la création, la gestion et l'administration de concours en ligne. Cette documentation vous guide à travers toutes les fonctionnalités de la plateforme.

### Structure de la documentation

- `index.md` : Page d'accueil et navigation principale
- `create-account.md` : Guide pour créer un compte

- `create-competition.md` : Guide pour créer une nouvelle compétition
- `work-with-competition/` : Guides pour gérer une compétition
  - `index.md` : Index des guides de gestion
  - `manage-participant.md` : Gestion des participants
  - `manage-area.md` : Gestion des zones/terrains
  - `general-configuration.md` : Configuration générale
  - `design-competition.md` : Conception de compétition

### Génération de la documentation

Pour générer la documentation HTML avec MkDocs :

```bash
cd docs
# Installation (première fois)
pip install mkdocs mkdocs-material

# Serveur de développement
mkdocs serve

# Construction pour la production
mkdocs build
```

La documentation générée sera disponible dans le dossier `docs/site/`.
